# Adhere to Output File Conventions

1. Identify the required output file format and naming conventions (e.g., `clean.csv`).
2. Ensure that the output file includes all necessary headers as specified (e.g., `order_id,timestamp_utc,region,amount_cents`).
3. Format the data in the output file according to the specified requirements (e.g., timestamp format as `YYYY-MM-DDTHH:MM:SSZ`).
4. Validate that the output file contains the correct number of rows and distinct entries as required.
5. Review the output file against the Acme conventions checklist before final submission.
